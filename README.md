# Sales Demand Forecasting using Machine Learning

## Project Overview

This project focuses on forecasting future sales using historical retail transaction data. The objective is to assist businesses in making data-driven decisions related to inventory management, demand planning, and revenue forecasting through predictive analytics.

## Business Problem

Accurate sales forecasting is critical for organizations to:

- Optimize inventory levels
- Reduce stock shortages and overstock situations
- Improve operational efficiency
- Support strategic business planning
- Enhance revenue forecasting accuracy

This project demonstrates the complete machine learning workflow for solving a real-world sales forecasting problem.



## Dataset Information

Dataset: Superstore Sales Dataset

The dataset contains historical sales records including:

- Order Details
- Customer Information
- Product Information
- Regional Sales Data
- Shipping Information
- Revenue and Profit Metrics



## Project Workflow

### 1. Data Collection and Understanding
- Imported and explored the dataset

### 2. Data Cleaning and Preprocessing
- Handled missing values

### 3. Exploratory Data Analysis (EDA)
- Sales trend analysis

### 4. Data Visualization
Generated visual insights using:
- Line Charts
- Bar Charts

- Scatter Plots

### 5. Machine Learning Model Development
- Feature Selection
- Train-Test Split
- Linear Regression Model Training
- Model Prediction

### 6. Model Evaluation
Performance evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
